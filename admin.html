Tải Về File Cập Nhật & Đưa Lên Server

Mỗi khi bạn thực hiện Thêm/Sửa/Xóa sản phẩm hoặc đổi màu sắc giao diện, hệ thống tự động lưu vào trình duyệt của bạn để bạn xem thử. Để đưa các thay đổi đó lên cho tất cả khách hàng trên internet nhìn thấy, bạn chỉ cần tải 2 file bên dưới và tải lên Server / Hosting:

1. File Cấu Hình Giao Diện

Chứa màu sắc, logo, hotline, địa chỉ và thông tin thương hiệu.

Vị trí đặt: Thư mục gốc website

2. File Danh Mục Sản Phẩm

Chứa toàn bộ danh sách sản phẩm, giá bán, hình ảnh và phân loại.

Vị trí đặt: Thư mục data/ của website

3. File Dữ Liệu Gốc JSON

Dùng để sao lưu dự phòng (backup) hoặc đồng bộ cơ sở dữ liệu nếu cần.

Vị trí đặt: Thư mục data/

Các Phương Án Đưa Lên Server / Hosting Dễ Dàng Nhất:

Cách 1: Hosting cPanel / DirectAdmin (Phổ biến nhất tại Việt Nam)

1. Đăng nhập vào cPanel > File Manager (Trình Quản Lý Tệp) > mở thư mục public_html.

2. Upload toàn bộ thư mục website này lên đó.

3. Khi có thay đổi sản phẩm: Chỉ cần upload đè 2 file config.js và data/products.js là xong!

Cách 2: Triển Khai Miễn Phí Trên Vercel / Netlify / GitHub Pages

1. Kéo thả thư mục website vào Vercel hoặc Netlify Drop.

2. Hệ thống cấp ngay tên miền và chứng chỉ bảo mật HTTPS (SSL) miễn phí vĩnh viễn.

3. Tốc độ tải trang siêu tốc toàn cầu nhờ mạng lưới CDN toàn diện.

Cách 3: Chạy Trên VPS Linux (Nginx / Apache)

1. Copy toàn bộ thư mục website vào thư mục /var/www/html/phongwatch.

2. Trỏ VirtualHost của Nginx hoặc Apache tới thư mục đó.

3. Không cần cài đặt Node.js hay cơ sở dữ liệu MySQL, website hoạt động cực nhẹ và mượt mà.
