PhongWatch Deploy System v2.0 ready. Nhấn nút "ĐẨY CONFIG LÊN GITHUB & AUTO DEPLOY" để tự động cập nhật website lên Cloudflare Pages.

Hướng Dẫn Kết Nối Cloudflare Pages Với GitHub (Chỉ cần làm 1 lần duy nhất)

1
Đăng Nhập Cloudflare & Tạo Dự Án Pages Mới

Truy cập dash.cloudflare.com → Menu trái chọn Workers & Pages → Bấm Create application → Chọn tab Pages → Bấm nút Connect to Git.

2
Ủy Quyền GitHub & Chọn Repository

Chọn tài khoản GitHub của bạn (cấp quyền truy cập nếu lần đầu), sau đó tìm và chọn repository: hanzozo2202/jinwatch-web → Bấm Begin setup.

3
Cấu Hình Build Cực Kỳ Đơn Giản (Static Site)

- Project name: jinwatch (hoặc tên bạn thích)
- Production branch: main
- Framework preset: None (Trang tĩnh thuần)
- Build command: (để trống hoàn toàn)
- Build output directory: / (hoặc để trống)

4
Nhấn "Save and Deploy" & Tận Hưởng Tự Động Hóa 100%

Cloudflare sẽ tự động kéo code, cấp phát tên miền https://jinwatch-xxx.pages.dev và chứng chỉ SSL HTTPS miễn phí. Kể từ lúc này, bất kỳ lần nào bạn chạy lệnh git push jin main hoặc ấn nút 1-Click Deploy ở trên, Cloudflare Pages sẽ tự động nhận diện và cập nhật website ngay lập tức trong 15-30 giây!

Cách Deploy Nhanh Bằng Lệnh Git Từ Máy Tính: 
git add .
git commit -m "Cập nhật cấu hình & giao diện"
git push jin main
Cloudflare Pages sẽ tự động kích hoạt tiến trình triển khai ngay khi lệnh push hoàn tất!

Tải Về File Cập Nhật Dự Phòng (Thủ Công)

Nếu bạn muốn lưu trữ bản sao lưu trên máy tính hoặc tải lên các Hosting truyền thống khác (cPanel, VPS), bạn có thể tải 3 file bên dưới:

1. File Cấu Hình Giao Diện

Chứa màu sắc, logo, hotline, địa chỉ và thông tin thương hiệu.

Vị trí đặt: Thư mục gốc website

2. File Danh Mục Sản Phẩm

Chứa toàn bộ danh sách sản phẩm, giá bán, hình ảnh và phân loại.

Vị trí đặt: Thư mục data/ của website

3. File Dữ Liệu Gốc JSON

Dùng để sao lưu dự phòng (backup) hoặc đồng bộ cơ sở dữ liệu nếu cần.

Vị trí đặt: Thư mục data/

Các Phương Án Hosting Khác:

Hosting cPanel / DirectAdmin (Phổ biến tại Việt Nam)

1. Đăng nhập vào cPanel > File Manager > mở thư mục public_html.

2. Upload toàn bộ thư mục website này lên đó.

3. Khi có thay đổi: Chỉ cần upload đè 2 file config.js và data/products.js là xong!

Triển Khai Trên Vercel / Netlify

1. Kéo thả thư mục website vào Vercel hoặc Netlify Drop.

2. Hệ thống cấp ngay tên miền và SSL miễn phí vĩnh viễn.

Chạy Trên VPS Linux (Nginx / Apache)

1. Copy toàn bộ website vào thư mục /var/www/html/phongwatch.

2. Trỏ VirtualHost của Nginx hoặc Apache tới thư mục đó.
